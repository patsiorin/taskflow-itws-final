# ITWS Final Project Requirements

For the final exam from the subject ITWS, the project should at least contain the following:

- A database with at least 2 tables
- At least one relation between tables
- CRUD operation on both tables
- Backend developed in any technology, for example Spring Boot
- Frontend developed in any technology, for example Vue
- Login is not required
- Calling an external API is not required
- Projects should be sent only as a GitHub repository containing the database dump as well
- Projects should be sent to the Teams chat
- Anything more than the minimal requirements will count towards more points
